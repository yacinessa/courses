Exercise 1: LED Blinking with Variations

Objective:

Create a program that makes a LED blink with three different speeds: slow (2 seconds), medium (500ms), and fast (100ms).

Sequence: 5 slow blinks → 10 medium blinks → 20 fast blinks → repeat

Current Speed: -
Ready to Start

Blinking Sequence:

5× Slow (2000ms)
10× Medium (500ms)
20× Fast (100ms)
Current Blink Count: 0

STM32 C Code:

#include "stm32f1xx.h"

int main(void) {
    // Initialize GPIOA Pin 5 as output
    RCC->APB2ENR |= RCC_APB2ENR_IOPAEN;
    GPIOA->CRL &= ~(0xF << 20);  // Clear bits 20-23
    GPIOA->CRL |= (0x2 << 20);   // Mode: Push-pull output, 50MHz
    
    while(1) {
        // Phase 1: 5 slow blinks (2000ms)
        for(int i = 0; i < 5; i++) {
            GPIOA->ODR ^= (1 << 5);  // Toggle PA5
            HAL_Delay(2000);
        }
        
        // Phase 2: 10 medium blinks (500ms)
        for(int i = 0; i < 10; i++) {
            GPIOA->ODR ^= (1 << 5);  // Toggle PA5
            HAL_Delay(500);
        }
        
        // Phase 3: 20 fast blinks (100ms)
        for(int i = 0; i < 20; i++) {
            GPIOA->ODR ^= (1 << 5);  // Toggle PA5
            HAL_Delay(100);
        }
    }
}
