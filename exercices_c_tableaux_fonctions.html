🔢 Exercices C Avancés : Tableaux et Fonctions

📋 Instructions

Ces exercices nécessitent une réflexion algorithmique intelligente. Chaque problème a un énoncé court mais demande des solutions optimisées en termes de temps et d'espace mémoire.

Exercice 1 : Le Détecteur d'Élément Manquant

⭐⭐⭐ int findMissingElement(int arr1[], int arr2[], int n);

Étant donné deux tableaux où arr2 contient tous les éléments de arr1 sauf un élément manquant et possiblement mélangés, trouver l'élément manquant avec une complexité temporelle O(n) et spatiale O(1).

Exercice 2 : Le Rotateur Cyclique

⭐⭐⭐⭐ void rotateArray(int arr[], int n, int k);

Faire tourner un tableau de n éléments vers la droite de k positions en place avec un temps O(n). Aucun espace supplémentaire autorisé sauf quelques variables. k peut être plus grand que n.

Exercice 3 : Le Maître des Sous-tableaux

⭐⭐⭐⭐⭐ int findMaxSubarraySum(int arr[], int n, int k);

Trouver la somme maximale de tout sous-tableau de longueur exactement k en temps O(n). Cas limites : tableau vide, k > n, nombres négatifs partout.

Exercice 4 : Le Compresseur de Matrice Creuse

⭐⭐⭐⭐ void compressSparseMatrix(int matrix[], int rows, int cols, int compressed[]);

Convertir une matrice creuse (beaucoup de zéros) en format compressé : [valeur1, col1, valeur2, col2, ...] contenant seulement les éléments non-zéros. Utiliser un espace O(m) où m est le nombre d'éléments non-zéros.

Exercice 5 : Le Maître de l'Union de Tableaux

⭐⭐⭐⭐ int* findUnion(int arr1[], int n1, int arr2[], int n2, int* resultSize);

Trouver l'union de deux tableaux triés (avec doublons) sans utiliser un espace proportionnel à la taille d'entrée. Le résultat doit être trié et ne contenir que des éléments uniques. Retourner à la fois le tableau et la taille.

Exercice 6 : Le Chasseur d'Élément Majoritaire

⭐⭐⭐⭐ int findMajorityElement(int arr[], int n);

Trouver l'élément apparaissant plus de n/2 fois en utilisant l'algorithme Boyer-Moore en temps O(n) et espace O(1). Vérifiez votre réponse - il pourrait ne pas toujours exister.

Exercice 7 : Le Générateur de Chemin en Spirale

⭐⭐⭐⭐⭐ void generateSpiralMatrix(int matrix[][], int n);

Générer une matrice n x n remplie avec les nombres 1 à n² en ordre spiralé (sens horaire, en partant du coin supérieur gauche). Retourner la matrice via le paramètre.

Exercice 8 : L'Optimiseur de la Somme de Deux

⭐⭐⭐ int* findTwoSum(int arr[], int n, int target, int* resultSize);

Trouver deux indices distincts dont les valeurs s'additionnent pour donner target. Retourner leurs indices. Doit être en temps O(n) et espace O(n). Retourner "non trouvé" si aucune solution n'existe.

Exercice 9 : Le Traqueur de Fréquence de Tableau

⭐⭐⭐⭐ void updateFrequency(int arr[], int n, int updates[], int m);

Étant donné un tableau initial arr et une liste de m mises à jour (valeurs à incrémenter), suivre efficacement les fréquences. Chaque mise à jour incrémente la fréquence de cette valeur. Contrainte de temps : O(n + m) au total.

Exercice 10 : La Médiane des Médianes

⭐⭐⭐⭐⭐ int findMedian(int arr1[], int n1, int arr2[], int n2);

Trouver la médiane de deux tableaux triés en temps O(log(min(n1,n2))). Fusion non autorisée. Gérer élégamment les cas de longueur totale paire/impaire.

Exercice 11 : La Permutation en Place

⭐⭐⭐⭐ void applyPermutation(int arr[], int perm[], int n);

Réorganiser le tableau arr selon la permutation perm où perm[i] indique où l'élément à la position i doit aller. Résoudre en place en utilisant O(1) espace supplémentaire avec détection de cycle.

Exercice 12 : Le Détecteur de Séquence

⭐⭐⭐⭐ int isSubsequence(char text[], int textLen, char pattern[], int patLen);

Vérifier si pattern est une sous-séquence de text (pas nécessairement contiguë). Retourner 1 si oui, 0 si non. Optimiser pour les grandes entrées où text est beaucoup plus long que pattern.

Exercice 13 : L'Algorithme de Prochaine Permutation

⭐⭐⭐⭐⭐ int nextPermutation(int arr[], int n);

Générer la prochaine permutation lexicographique des éléments du tableau en place. Retourner 1 si la prochaine permutation existe, 0 si la permutation actuelle est la dernière. Implémenter l'algorithme célèbre utilisé dans next_permutation() de C++.

Exercice 14 : Le Préprocesseur de Somme de Plage

⭐⭐⭐⭐⭐ void buildPrefixSum(int arr[], int n, int prefix[]);
int rangeSumQuery(int prefix[], int l, int r);

Étant donné un tableau, construire un tableau de somme préfixe pour des requêtes de somme de plage efficaces en temps O(1). Démontrer avec plusieurs requêtes. Gérer les cas limites (plages vides, indices invalides).

Exercice 15 : Le Maximum de Fenêtre Coulissante

⭐⭐⭐⭐⭐ int* slidingWindowMax(int arr[], int n, int k, int* resultSize);

Trouver le maximum dans chaque fenêtre coulissante de taille k à travers le tableau. Résoudre en temps O(n) en utilisant une file double. Retourner le tableau de résultats et sa taille.

Exercice 16 : Le Problème de Partition de Tableau

⭐⭐⭐⭐⭐ int canPartitionArray(int arr[], int n, int targetSum);

Déterminer si un tableau peut être partitionné en deux sous-ensembles avec une somme égale (problème de somme de sous-ensemble). Utiliser la programmation dynamique avec temps O(n*sum) et optimiser l'espace à O(sum).

Exercice 17 : La Fusion de K Tableaux Triés

⭐⭐⭐⭐⭐ int* mergeKSortedArrays(int arrays[][MAX_SIZE], int sizes[], int k, int* resultSize);

Fusionner k tableaux triés en un tableau trié unique. Optimiser en temps O(n log k) en utilisant un tas minimum ou diviser-pour-régner. Gérer les tableaux de longueurs différentes.

Exercice 18 : Le Sous-tableau de Produit Maximum

⭐⭐⭐⭐⭐ int maxProductSubarray(int arr[], int n);

Trouver le sous-tableau contigu avec le produit maximum. Gérer les nombres positifs et négatifs, y compris les zéros. Cas limite quand le tableau ne contient qu'un seul élément.

Exercice 19 : Le Validateur de Sudoku

⭐⭐⭐⭐ int isValidSudoku(int board[][9]);

Valider un plateau de Sudoku partiellement rempli. Vérifier que chaque ligne, colonne et sous-grille 3x3 contient des chiffres uniques (1-9) ou des cellules vides. Retourner 1 si valide, 0 sinon.

Exercice 20 : Le Compteur de Sous-séquence Croissante Longue

⭐⭐⭐⭐⭐ int longestIncreasingSubsequenceLength(int arr[], int n);

Trouver la longueur de la sous-séquence croissante la plus longue. Optimiser en temps O(n log n) en utilisant la recherche binaire avec la programmation dynamique. Compter aussi combien de LIS différentes existent.

🎯 Règles du Défi :

  1. Aucune variable globale - tout via les paramètres
  2. Gestion d'erreurs appropriée pour les cas limites
  3. Documentation claire de l'approche algorithmique
  4. Analyse de complexité temporelle/spatiale efficace
  5. Tester avec divers cas limites (tableaux vides, éléments uniques, toutes valeurs identiques, etc.)
