🔐 Exercices C Avancés : Cryptographie et Chiffrement

🔒 Aperçu de la Cryptographie

Ces exercices explorent les concepts fondamentaux de la cryptographie moderne et classique, du chiffrement symétrique aux algorithmes asymétriques, en passant par les fonctions de hachage et les protocoles de sécurité.

Exercice 1 : Chiffre de César Avancé

⭐⭐⭐ void caesarCipher(char text[], int key, char result[]);
void caesarDecrypt(char cipher[], int key, char result[]);

Implémenter un chiffre de César avec gestion des caractères accentués, ponctuation et espaces. Inclure la prise en charge Unicode et permettre des clés négatives pour le déchiffrement automatique.

Concepts : Arithmétique modulaire, manipulation de caractères Unicode, cryptanalyse de fréquence

Exercice 2 : Chiffre de Vigenère Dynamique

⭐⭐⭐⭐ void vigenereCipher(char plaintext[], char key[], char ciphertext[]);
char* vigenereCrack(char ciphertext[], char dictionary[]);

Créer un chiffre de Vigenère avec clé dynamique et cassage automatique basé sur l'analyse de fréquence. Détecter automatiquement la longueur de clé et proposer des clés candidates.

Concepts : Analyse de fréquence, corrélation statistique, attaque par clé répétitive

Exercice 3 : AES Simplified Implementation

⭐⭐⭐⭐⭐ void aesEncryptECB(unsigned char plaintext[], unsigned char key[], unsigned char ciphertext[]);
void aesDecryptECB(unsigned char ciphertext[], unsigned char key[], unsigned char plaintext[]);

Implémenter une version simplifiée d'AES (Advanced Encryption Standard) en mode ECB avec toutes les transformations : SubBytes, ShiftRows, MixColumns, AddRoundKey.

Avertissement : Pour usage éducatif uniquement. Utiliser des implémentations certifiées pour la production.

Exercice 4 : RSA avec Génération de Clés

⭐⭐⭐⭐⭐ void generateRSAKeys(unsigned long* publicKey, unsigned long* privateKey, unsigned long* modulus);
unsigned long rsaEncrypt(unsigned long message, unsigned long publicKey, unsigned long modulus);
unsigned long rsaDecrypt(unsigned long cipher, unsigned long privateKey, unsigned long modulus);

Implémenter le cryptosystème RSA complet avec génération de clés, test de primalité de Miller-Rabin, algorithme d'Euclide étendu, et chiffrement/déchiffrement. Gérer les grands entiers.

Concepts : Théorie des nombres, arithmétique modulaire, fonctions à sens unique, cryptographie asymétrique

Exercice 5 : Hachage SHA-256

⭐⭐⭐⭐⭐ void sha256Hash(unsigned char data[], int length, unsigned char hash[]);
int verifyIntegrity(unsigned char data[], int length, unsigned char expectedHash[]);

Implémenter l'algorithme de hachage SHA-256 complet avec padding, traitement des blocs, fonctions de compression et constantes de hachage. Inclure la vérification d'intégrité des données.

Concepts : Fonctions de hachage cryptographique, Merkle-Damgård construction, compression unidirectionnelle

Exercice 6 : Générateur de Nombres Pseudo-Aléatoires Sécurisés

⭐⭐⭐⭐ void csprngInit(unsigned int seed[]);
unsigned int csprngNext();
double csprngUniform();
void csprngBytes(unsigned char* buffer, int length);

Implémenter un générateur de nombres pseudo-aléatoires cryptographiquement sûr basé sur l'algorithme ChaCha20 ou similar. Inclure différents types de sortie (entiers, flottants, octets).

Concepts : Entropie, états internes, non-linéarité, période maximale

Exercice 7 : Détection et Cassage de XOR Bit-à-Bit

⭐⭐⭐⭐⭐ void xorCipher(unsigned char data[], unsigned char key[], int dataLen, int keyLen, unsigned char result[]);
unsigned char* xorBruteForce(unsigned char cipher[], int cipherLen, char dictionary[]);

Implémenter le chiffrement XOR avec détection automatique de longueur de clé et cassage par force brute en utilisant l'analyse de fréquences English. Optimiser pour les grandes données.

Concepts : XOR logique, cryptanalyse statistique, Hamming distance, attaque par clé répétitive

Exercice 8 : Chiffrement par Flux (Stream Cipher)

⭐⭐⭐⭐⭐ void streamCipherInit(int seed);
void encryptStream(unsigned char plaintext[], unsigned char ciphertext[], int length);
void decryptStream(unsigned char ciphertext[], unsigned char plaintext[], int length);

Créer un chiffrement par flux basé sur LFSR (Linear Feedback Shift Register) avec plusieurs polynômes de rétroaction et mécanisme de synchronisation. Implémenter la synchronisation automatique.

Concepts : LFSR, feedback polynomial, synchronisation de flux, attaques par synchronisation

Exercice 9 : Protocole de Diffie-Hellman

⭐⭐⭐⭐⭐ unsigned long diffieHellmanGeneratePrivate(unsigned long prime, unsigned long generator);
unsigned long diffieHellmanComputePublic(unsigned long privateKey, unsigned long generator, unsigned long prime);
unsigned long diffieHellmanSharedSecret(unsigned long privateKey, unsigned long otherPublic, unsigned long prime);

Implémenter l'échange de clés Diffie-Hellman avec génération de paramètres sûrs, calcul d'exponentiation modulaire efficace et vérification de la légitimité des paramètres.

Concepts : Problème du logarithme discret, échange de clés sécurisé, man-in-the-middle defense

Exercice 10 : Authentification par Message (MAC)

⭐⭐⭐⭐ void hmacSha256(unsigned char key[], int keyLen, unsigned char message[], int msgLen, unsigned char mac[]);
int verifyHmac(unsigned char key[], int keyLen, unsigned char message[], int msgLen, unsigned char expectedMac[]);

Implémenter HMAC-SHA256 pour l'authentification des messages avec construction Merkle-Damgård, padding de clé, et fonctionnement en mode inner/outer.

Concepts : Message Authentication Code, key derivation, hash-based constructions, tamper detection

Exercice 11 : Base64 Encoding/Decoding Sécurisé

⭐⭐⭐ int base64Encode(unsigned char* data, int length, char* encoded);
int base64Decode(char* encoded, unsigned char* data);
int base64UrlEncode(unsigned char* data, int length, char* encoded);

Implémenter Base64 avec gestion des caractères d'échappement, validation des données d'entrée, et variante URL-safe. Gérer les cas d'erreur et tampons insuffisants.

Exercice 12 : Chiffrement de Hill (Matrice)

⭐⭐⭐⭐ void hillCipherEncrypt(char plaintext[], int keyMatrix[][], int n, char ciphertext[]);
void hillCipherDecrypt(char ciphertext[], int keyMatrix[][], int n, char plaintext[]);
int invertMatrix(int matrix[][], int n, int inverse[][]);

Implémenter le chiffre de Hill avec matrices de taille variable, calcul de l'inverse modulaire, et gestion des caracteres non alphabétiques. Inclure la cryptanalyse par matrice inconnue.

Concepts : Algèbre linéaire, matrices modulaires, calculs d'inverse, cryptanalyse linéaire

Exercice 13 : Signatures Numériques RSA

⭐⭐⭐⭐⭐ void rsaSign(unsigned char message[], int msgLen, unsigned char signature[], unsigned long privateKey, unsigned long modulus);
int rsaVerify(unsigned char message[], int msgLen, unsigned char signature[], unsigned long publicKey, unsigned long modulus);

Implémenter les signatures numériques RSA avec hachage SHA-256, padding PSS (Probabilistic Signature Scheme), et vérification de signature. Gérer l'attaque par falsification.

Concepts : Signatures numériques, hash-then-sign, protection against existential forgery, non-répudiation

Exercice 14 : Chiffrement par Substitution Polynomiale

⭐⭐⭐⭐ void polySubCipher(unsigned char data[], int length, unsigned char key[], int keyLen, unsigned char result[]);
int findPolyKeyLength(unsigned char cipher[], int cipherLen);

Créer un chiffrement basé sur la substitution polynomiale avec détection automatique de longueur de clé. Implémenter l'attaque par analyse de corrélation.

Concepts : Fonctions polynomiales, corrélation, attaque par clé incomplète, analyse fréquentielle multidimensionnelle

Exercice 15 : Cryptanalyse par Analyse de Fréquence

⭐⭐⭐⭐ void frequencyAnalysis(char cipher[], int length, double frequencies[256]);
char* crackFrequencyCipher(char cipher[], int length, char dictionary[]);

Créer un système complet de cryptanalyse par analyse de fréquences avec génération de rapports statistiques, estimation de longueur de clé, et reconstruction automatique.

Concepts : Statistiques de fréquence, chi-squared test, maximum likelihood, dictionnaire de fréquence

Exercice 16 : Zero-Knowledge Proof Simple

⭐⭐⭐⭐⭐ void zkpCommit(int secret, int* commitment, int* random);
int zkpChallenge(int commitment);
int zkpResponse(int challenge, int secret, int random);
int zkpVerify(int commitment, int challenge, int response, int* publicHash);

Implémenter une preuve à divulgation nulle de connaissance basée sur le protocole de Schnorr pour démontrer la connaissance d'un secret sans le révéler.

Concepts : Zero-knowledge proofs, commitments, challenges, perfect zero-knowledge, interactive protocols

Exercice 17 : Masquage d'Information (Steganographie)

⭐⭐⭐⭐ int hideMessageInImage(unsigned char image[], int width, int height, char message[], unsigned char stegoImage[]);
char* extractMessageFromImage(unsigned char stegoImage[], int width, int height);

Implémenter une technique de stéganographie pour cacher des messages dans des images en modifiant les bits de poids faible (LSB). Inclure détection et extraction automatique.

Concepts : Steganographie, LSB manipulation, capacité de masquage, détection statistique, forensics

Exercice 18 : Chiffrement Quantique Simulé

⭐⭐⭐⭐⭐ void quantumKeyDistribution(int qubits[], int length, int basis[], int results[]);
int detectEavesdropping(int aliceResults[], int bobResults[], int basis[], int length);
void generateQuantumKey(int siftedKey[], int secureKey[], int length);

Simuler le protocole de distribution quantique de clés BB84 avec génération de qubits, mesure dans différentes bases, et détection d'interception. Implémenter la reconciliation d'erreur.

Concepts : Cryptographie quantique, polarisation de photons, bases de mesure, théorème de non-clonage, eavesdropping detection

Exercice 19 : Authentification Biométrique Simulée

⭐⭐⭐⭐ double computeMinutiae(double features[][], int numFeatures);
int matchBiometric(double template1[], double template2[], double threshold);
double fuzzyExtractor(double biometric[], int length, char* helper);

Implémenter un système d'authentification biométrique simulé avec extraction de minutiae, correspondance floue, et fuzzy extractors pour la protection des templates.

Concepts : Biométrie, minutiae extraction, fuzzy matching, template protection, privacy-preserving biometrics

Exercice 20 : Blockchain Simplifiée

⭐⭐⭐⭐⭐ typedef struct Block { int index; char data[256]; int timestamp; char previousHash[65]; char hash[65]; } Block;
void mineBlock(Block* block, int difficulty);
int validateChain(Block chain[], int length);
void addTransaction(Block* block, char transaction[]);

Créer une blockchain simplifiée avec proof-of-work, calcul de hash SHA-256, validation de chaîne, et mécanisme de consensus. Inclure détection de blockchain fork.

Concepts : Blockchain, proof-of-work, hash chains, distributed consensus, tampering detection, consensus algorithms
