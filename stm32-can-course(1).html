Fondements de la Conversion Numérique

Avant de toucher un registre du STM32, maîtrisez les quatre piliers théoriques universels — ils s'appliquent à tout CAN, pas seulement au STM32.

F.1 Fondamentaux

① Échantillonnage

Un signal analogique est continu dans le temps. Un système numérique ne peut pas traiter l'infini — il prélève des mesures à des instants discrets.

FIGURE F.1 — Points jaunes = échantillons prélevés à fréquence fs = 1/Ts

📐 Définitions Essentielles

SymboleNomUnité
TsPériode d'échantillonnagesecondes
fsFréquence d'échantillonnageHz = 1/Ts
x(t)Signal analogique continuvolts [V]
x[n]= x(n·Ts) — séquence discrèten = 0,1,2…

⚡ Ce qui se passe physiquement

À chaque instant nTs, un transistor MOSFET interne se ferme quelques nanosecondes. La tension d'entrée est capturée sur le condensateur d'échantillonnage (~4 pF). Le MOSFET se rouvre. Le CAN convertit cette tension en binaire.

ℹ️
Sur STM32F4

Le temps d'ouverture/fermeture est contrôlé par le registre SMPR (Sampling Time). 3 à 480 cycles d'horloge CAN disponibles.

F.2 Fondamentaux

② Blocage — Sample & Hold

La conversion SAR prend plusieurs cycles. Pendant ce temps, le signal d'entrée ne doit pas changer. Le S&H "gèle" la tension le temps de la conversion.

PHASE 01
TRACK
S1 fermé. Condensateur C se charge jusqu'à Vin. Vout = Vin en temps réel.
PHASE 02
HOLD
S1 ouvert. Charge isolée. Vout reste constant même si Vin change. SAR commence.
PHASE 03
CONVERSION
SAR compare Vout (bloqué) bit par bit. 12 cycles d'horloge pour 12 bits. Vout stable.
PHASE 04
ACQUISITION
S1 se referme. Condensateur se recharge vers nouvelle valeur Vin. Durée ≥ t_s.
⚠️
Pourquoi le temps d'acquisition compte

Le condensateur charge via la résistance source (capteur + filtre). Si R_source est grande (ex. thermistance 10 kΩ), il faut plus de temps. C'est pourquoi on utilise ADC_SAMPLETIME_480CYCLES pour sources haute impédance.

F.3 Fondamentaux

③ Théorème de Shannon-Nyquist

À quelle fréquence faut-il échantillonner ? Trop lentement → repliement spectral (aliasing). Shannon démontre la condition minimale.

THÉORÈME DE SHANNON-NYQUIST (1949)
fs ≥ 2 · fmax

Pour reconstruire parfaitement un signal de fréquence max f_max, la fréquence d'échantillonnage f_s doit être au moins le double.

f_Nyquist = f_s / 2
Fréquence de Nyquist = limite max représentable
STM32F4 : f_s max = 2,4 MSPS
→ Représente signaux jusqu'à 1,2 MHz
✅ BON ÉCHANTILLONNAGE (f_s > 2·f_max)
❌ REPLIEMENT SPECTRAL (f_s < 2·f_max)

📝 Exercices de Vérification

❓ Q1 — Théorème de Shannon

Un capteur de vibrations produit un signal dont la fréquence maximale est 8 kHz. Quelle est la fréquence d'échantillonnage minimale ?

A 4 000 Hz
B 8 000 Hz
C 16 000 Hz
D 32 000 Hz
✅ C est correct ! — f_s ≥ 2 × 8 000 = 16 000 Hz. En pratique, on choisit 5–10× f_max pour une bonne marge.

❓ Q2 — Résolution et LSB

CAN 12 bits, V_REF = 3,3 V, valeur brute lue = 1638. Quelle est la tension d'entrée ?

A 1,638 V
B 1,320 V
C 1,650 V
D 0,400 V
✅ B est correct ! — V = (1638 / 4095) × 3,3 = 0,4 × 3,3 = 1,320 V. On divise par 4095 (= 2¹² − 1), pas 4096.

❓ Q3 — Cycles SAR

CAN SAR 12 bits — combien de cycles d'horloge CAN pour la conversion seule (sans échantillonnage) ?

A 8 cycles
B 12 cycles
C 12,5 cycles
D 16 cycles
✅ C est correct ! — 12,5 cycles : 12 décisions de bits + 0,5 cycle de synchronisation. Les 3–480 cycles de S/H s'ajoutent avant.

❓ Q4 — Temps de conversion total

APB2 = 84 MHz, prédiviseur /4 → f_CAN = 21 MHz. Temps d'échantillonnage = 84 cycles. Durée totale en µs ?

A 0,595 µs
B 4,0 µs
C 4,595 µs
D 23,4 µs
✅ C est correct ! — t = (84 + 12,5) / 21 000 000 = 96,5 / 21M = 4,595 µs.
01 Module

Qu'est-ce qu'un CAN ?

Le monde réel est analogique. Les MCU ne comprennent que les 1 et 0. Le CAN est le pont qui traduit.

V_entrée = (Valeur_CAN / (2^N − 1)) × V_REF

📡 Échantillonnage

Instantanés à intervalles réguliers. Selon Nyquist : échantillonner à ≥ 2× f_max pour éviter l'aliasing.

📊 Quantification

Chaque échantillon est associé à un des 2^N niveaux. STM32F4 = 12 bits → 4096 niveaux (0 à 4095).

🔢 Codage

Le niveau est stocké en binaire dans ADC_DR. Le CPU lit ce registre et convertit en grandeur physique.

02 Module

Architecture du CAN STM32F4

Jusqu'à trois CAN 12 bits (ADC1, ADC2, ADC3), jusqu'à 19 canaux, capteurs internes inclus.

⚡ Architecture SAR

Recherche binaire : compare l'entrée bit par bit à une tension générée par un CNA interne. 12 cycles = résultat 12 bits.

🕐 Horloge CAN

Dérivée de l'horloge APB2 (max 84 MHz) divisée par 2, 4, 6 ou 8. Horloge CAN max = 36 MHz.

📦 Trois instances

ADC1, ADC2, ADC3. Fonctionnent indépendamment ou en mode double/triple. Seul ADC1 est connecté au capteur de température interne.

🎯 Modes de conversion

  • Unique : Une conversion puis stop
  • Continu : Boucle automatique
  • Balayage : Séquence de canaux
  • Discontinu : N canaux par déclenchement
⚠️
Plage de tension d'entrée

Toujours entre V_REF− (GND) et V_REF+. Sur Nucleo/Discovery, V_REF+ = VDD = 3,3 V. N'appliquez jamais plus de 3,3 V sur une broche CAN.

05 Module

CAN en Mode Scrutation

Le CPU démarre une conversion, attend (bloque) jusqu'à la fin, lit le résultat. Simple, parfait pour les lectures basse fréquence.

uint32_t can_brut;
float    tension;
char     buf[64];

while (1)
{
  /* 1 — Démarrer une conversion */
  HAL_ADC_Start(&hadc1);
  /*    → Met SWSTART dans ADC_CR2 → CAN commence à échantillonner PA0 */

  /* 2 — Attendre la fin de conversion */
  HAL_ADC_PollForConversion(&hadc1, 100);
  /*    → Scrute le bit FCA dans ADC_SR en boucle serrée (timeout 100ms) */

  /* 3 — Lire la valeur convertie */
  can_brut = HAL_ADC_GetValue(&hadc1);
  /*    → Lit ADC1→DR (0..4095) — la lecture efface aussi FCA */

  /* 4 — Arrêter le CAN */
  HAL_ADC_Stop(&hadc1);

  /* 5 — Convertir brut → tension */
  tension = ((float)can_brut / 4095.0f) * 3.3f;

  /* 6 — Envoyer via UART */
  sprintf(buf, "CAN: %lu | V: %.3f V\r\n", can_brut, tension);
  HAL_UART_Transmit(&huart2, (uint8_t*)buf, strlen(buf), 100);

  HAL_Delay(500);
}
06 Module

CAN avec DMA — Charge CPU Nulle

Le DMA transfère les résultats directement en RAM sans intervention du CPU. Approche professionnelle pour l'acquisition continue haute vitesse.

ℹ️
Correspondance DMA pour ADC1

Sur STM32F4, ADC1 → DMA2, Flux 0, Canal 0. Fixé en matériel. Vérifiez le tableau "DMA2 request mapping" dans le manuel de référence.

/* Dans CubeMX : ADC1 → DMA Settings → Ajouter → DMA2 Flux0 → Circulaire */

uint32_t buf_dma[4];            /* 4 canaux, mis à jour en continu */
volatile uint8_t dma_pret = 0;

/* Dans main(), après MX_ADC1_Init() */
HAL_ADC_Start_DMA(&hadc1, buf_dma, 4);
/*   → Mode CIRCULAIRE : redémarre automatiquement. CPU LIBRE ! */

while (1)
{
  if (dma_pret) {
    dma_pret = 0;
    float ch0 = (buf_dma[0] / 4095.0f) * 3.3f;
    float ch1 = (buf_dma[1] / 4095.0f) * 3.3f;
    afficher_ecran(ch0, ch1);
  }
}

/* Rappel DMA complet */
void HAL_ADC_ConvCpltCallback(ADC_HandleTypeDef *hadc)
{
  if (hadc->Instance == ADC1)
    dma_pret = 1;
}
07 Module

Mode Multi-Canaux et Balayage

En mode balayage, le CAN parcourt automatiquement une séquence de canaux. Combiné au DMA : tous les résultats en RAM sans aucune intervention CPU.

hadc1.Init.ScanConvMode          = ENABLE;    /* balayage tous canaux */
hadc1.Init.NbrOfConversion       = 4;        /* longueur séquence    */
hadc1.Init.ContinuousConvMode    = ENABLE;    /* cycle permanent      */
hadc1.Init.DMAContinuousRequests = ENABLE;    /* DMA redémarre avec CAN */

ADC_ChannelConfTypeDef sConfig;

/* Rang 1 → Canal 0 (PA0) — Potentiomètre */
sConfig.Channel = ADC_CHANNEL_0; sConfig.Rank = 1;
sConfig.SamplingTime = ADC_SAMPLETIME_84CYCLES;
HAL_ADC_ConfigChannel(&hadc1, &sConfig);

/* Rang 2 → Canal 1 (PA1) — LDR */
sConfig.Channel = ADC_CHANNEL_1; sConfig.Rank = 2;
HAL_ADC_ConfigChannel(&hadc1, &sConfig);

/* Rang 3 → Canal 4 (PA4) — Batterie */
sConfig.Channel = ADC_CHANNEL_4; sConfig.Rank = 3;
HAL_ADC_ConfigChannel(&hadc1, &sConfig);

/* Rang 4 → Capteur Temp interne ⚠ Activer TSVREFE ! Min 480 cycles ! */
sConfig.Channel      = ADC_CHANNEL_TEMPSENSOR;
sConfig.Rank         = 4;
sConfig.SamplingTime = ADC_SAMPLETIME_480CYCLES;
HAL_ADC_ConfigChannel(&hadc1, &sConfig);

uint32_t buf_can[4];
HAL_ADC_Start_DMA(&hadc1, buf_can, 4);

Problème 01
Lecture d'un Potentiomètre
Difficulté : ⭐ Débutant · Canal unique, mode scrutation
📋 Énoncé

Potentiomètre 10 kΩ entre 3,3 V et GND, curseur sur PA0. Lire en scrutation toutes les 500 ms, convertir en tension et pourcentage, envoyer via UART2 à 115 200 bauds. CAN : 12 bits, horloge APB2/4 = 21 MHz.

❓ Questions
Q1
Formule : Valeur brute = 3072, V_REF = 3,3 V, 12 bits → Tension en volts ?
💡 V = (brut / 4095) × 3,3
Q2
Séquence HAL : Les 4 fonctions HAL dans l'ordre exact pour une conversion unique ?
💡 Start → Poll → Get → Stop
Q3
Temps : Avec 3 cycles d'échantillonnage @ 21 MHz, durée d'une conversion en µs ?
💡 t = (S/H + 12,5) / f_CAN
Q4
Pourcentage : Formule C pour calculer 0–100% à partir de la valeur brute.
RÉPONSE Q1

V = (3072 / 4095) × 3,3 = 0,7502 × 3,3 = 2,476 V

RÉPONSE Q2

HAL_ADC_Start() → HAL_ADC_PollForConversion() → HAL_ADC_GetValue() → HAL_ADC_Stop()

RÉPONSE Q3

t = (3 + 12,5) / 21 000 000 = 0,738 µs ≈ 1,35 MSPS max

RÉPONSE Q4

float pct = ((float)brut / 4095.0f) * 100.0f;

uint32_t brut; float tension, pct; char buf[80];

while (1) {
  HAL_ADC_Start(&hadc1);
  HAL_ADC_PollForConversion(&hadc1, 100);
  brut = HAL_ADC_GetValue(&hadc1);
  HAL_ADC_Stop(&hadc1);

  tension = ((float)brut / 4095.0f) * 3.3f;
  pct     = ((float)brut / 4095.0f) * 100.0f;

  sprintf(buf, "[%.*s%.*s] %5.1f%%  %.3fV\r\n",
          (int)(pct/10), "##########",
          10-(int)(pct/10), "          ", pct, tension);
  HAL_UART_Transmit(&huart2, (uint8_t*)buf, strlen(buf), 100);
  HAL_Delay(500);
}

Problème 02
Capteur de Température Interne
Difficulté : ⭐⭐ Intermédiaire · Canal interne, calibration usine
📋 Énoncé

Le STM32F407 intègre un capteur sur ADC1_IN16. Calibration usine : TS_CAL1 @ 0x1FFF7A2C (30°C), TS_CAL2 @ 0x1FFF7A2E (110°C). Afficher température en °C, 1 décimale, chaque seconde.

❓ Questions
Q1
Activation : Quel bit dans quel registre activer avant de lire le capteur ?
💡 TSVREFE dans ADC_CCR
Q2
Temps d'échantillonnage : Minimum 10 µs requis. Combien de cycles @ 21 MHz ? Quelle constante HAL ?
💡 N ≥ 10µs × 21MHz = 210 cycles
Q3
Formule calibration usine : Interpolation linéaire entre CAL1 (30°C) et CAL2 (110°C).
RÉPONSE Q1

Bit TSVREFE (bit 23) dans ADC_CCR. Désactivé par défaut pour économiser l'énergie.

RÉPONSE Q2

N ≥ 210 cycles → choisir 480 cycles (ADC_SAMPLETIME_480CYCLES).

RÉPONSE Q3

t = (110.0f-30.0f)/((float)(*cal2-*cal1)) * ((float)brut - *cal1) + 30.0f;

float Lire_Temperature(void) {
  uint32_t brut;
  ADC_ChannelConfTypeDef sConfig = {0};

  ADC->CCR |= ADC_CCR_TSVREFE;      /* Activer capteur interne */

  sConfig.Channel      = ADC_CHANNEL_TEMPSENSOR;
  sConfig.Rank         = 1;
  sConfig.SamplingTime = ADC_SAMPLETIME_480CYCLES;
  HAL_ADC_ConfigChannel(&hadc1, &sConfig);

  HAL_ADC_Start(&hadc1);
  HAL_ADC_PollForConversion(&hadc1, 100);
  brut = HAL_ADC_GetValue(&hadc1);
  HAL_ADC_Stop(&hadc1);

  uint16_t *cal1 = (uint16_t*)0x1FFF7A2C;
  uint16_t *cal2 = (uint16_t*)0x1FFF7A2E;
  return (110.0f-30.0f) / ((float)(*cal2-*cal1))
         * ((float)brut - *cal1) + 30.0f;
}

Problème 03
Contrôle Automatique de Luminosité (LDR)
Difficulté : ⭐⭐ Intermédiaire · Hystérésis
📋 Énoncé

LDR (100Ω – 1MΩ) + résistance fixe 10 kΩ en diviseur de tension → PA1 (ADC1_IN1). Allumer LED sur PD12 si sombre (CAN > 3000), éteindre si clair (CAN < 1000). Implémenter une zone d'hystérésis pour éviter le scintillement.

RÉPONSE — HYSTÉRÉSIS

Deux seuils (3000 et 1000) créent une zone morte. Avec un seul seuil à 2000, un signal oscillant entre 1980–2020 ferait commuter la LED des dizaines de fois par seconde.

#define SEUIL_SOMBRE  3000
#define SEUIL_CLAIR   1000

static uint8_t led_on = 0;

HAL_ADC_Start(&hadc1);
HAL_ADC_PollForConversion(&hadc1, 100);
uint32_t brut = HAL_ADC_GetValue(&hadc1);
HAL_ADC_Stop(&hadc1);

if (!led_on && brut > SEUIL_SOMBRE) {
  led_on = 1;
  HAL_GPIO_WritePin(GPIOD, GPIO_PIN_12, GPIO_PIN_SET);
} else if (led_on && brut < SEUIL_CLAIR) {
  led_on = 0;
  HAL_GPIO_WritePin(GPIOD, GPIO_PIN_12, GPIO_PIN_RESET);
}

Problème 04
Moniteur de Tension Batterie LiPo
Difficulté : ⭐⭐⭐ Avancé · Diviseur de tension, suréchantillonnage
📋 Énoncé

Batterie LiPo 1S : 3,0 V (vide) → 4,2 V (pleine). Diviseur R1=R2=100 kΩ → PA4. Suréchantillonnage ×16. Afficher tension réelle, SoC (0–100%), alarme si V < 3,2 V.

RÉPONSE — Circuit

Rapport = 0,5. CAN voit 1,5 V à 2,1 V → sûr. V_bat = V_CAN × 2.

RÉPONSE — Suréchantillonnage

16 mesures → +log₂(16) = +4 bits effectifs → résolution effective 16 bits.

#define N_OS  16
uint32_t somme = 0;
for (int i=0; i<N_OS; i++) {
  HAL_ADC_Start(&hadc1);
  HAL_ADC_PollForConversion(&hadc1, 10);
  somme += HAL_ADC_GetValue(&hadc1);
  HAL_ADC_Stop(&hadc1);
}
float v_can = ((float)(somme/N_OS) / 4095.0f) * 3.3f;
float v_bat = v_can * 2.0f;   /* annuler diviseur R1=R2 */
float soc   = (v_bat-3.0f)/(4.2f-3.0f)*100.0f;
if(soc<0)soc=0; if(soc>100)soc=100;
HAL_GPIO_WritePin(GPIOD, GPIO_PIN_14,
  v_bat<3.2f ? GPIO_PIN_SET : GPIO_PIN_RESET);

Problème 05
Joystick Double Axe avec DMA
Difficulté : ⭐⭐⭐ Avancé · 2 canaux, DMA balayage, zone morte
📋 Énoncé

Joystick : axe X sur PA0 (CH0), axe Y sur PA1 (CH1). Lire les deux axes simultanément avec DMA balayage continu. Normaliser −1,0 à +1,0. Zone morte ±150 pts autour du centre (2048). 50 Hz de mise à jour.

RÉPONSE — DMA

ADC1 → DMA2 Flux 0 Canal 0 → Mode Circulaire → Taille mémoire Word. ScanConvMode=ENABLE, NbrOfConversion=2, ContinuousConvMode=ENABLE, DMAContinuousRequests=ENABLE.

RÉPONSE — Tampon Global

Le tampon DMA doit être global car le DMA y accède directement en arrière-plan. Variable locale = adresse sur la pile → peut être écrasée ou libérée.

uint32_t buf_joy[2];   /* [0]=X, [1]=Y — GLOBAL ! */
#define CENTRE  2048
#define DZ      150

float zone_morte(uint32_t brut) {
  int32_t e = (int32_t)brut - CENTRE;
  if (e > -DZ && e < DZ) return 0.0f;
  float v = ((float)e - (float)(e>0 ? DZ : -DZ)) / (float)(CENTRE-DZ);
  if(v> 1.0f)v= 1.0f; if(v<-1.0f)v=-1.0f; return v;
}

/* Dans main() */
HAL_ADC_Start_DMA(&hadc1, buf_joy, 2);

while(1) {
  float x = zone_morte(buf_joy[0]);
  float y = zone_morte(buf_joy[1]);
  /* PWM moteur : ARR=1000, 500=arrêt */
  __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, (uint32_t)(500 + x*500));
  __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_2, (uint32_t)(500 + y*500));
  HAL_Delay(20);  /* 50 Hz */
}

  • 3–15 cycles : Sources <1 kΩ

  • 84–480 cycles : Haute impédance (>10 kΩ)
  • 480 cycles : Capteur temp (obligatoire)

🔌 Filtre Anti-Repliement

R = 1 kΩ en série + C = 100 nF vers GND. f_coupure ≈ 1,6 kHz. Placer au plus près de la broche MCU.

🚫 À Ne Jamais Faire

  • ❌ >3,3 V sur une broche CAN sans protection
  • ❌ Broche GPIO flottante comme entrée CAN
  • ❌ Oublier volatile sur variables partagées DMA
  • ❌ TSVREFE non activé pour le capteur interne
  • ❌ Tampon DMA sur la pile (variable locale)
